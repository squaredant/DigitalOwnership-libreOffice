# Changelog

## 1.0.5 - Current release

- Published versioned LibreOffice package `digitalownership-1.0.5.oxt`.
- Kept `digitalownership.oxt` as a compatibility alias.
- Supports email-linked account registration without a crypto wallet.
- Supports direct wallet registration for users who intentionally use a crypto wallet.
- Creates local archive records without writing registration metadata into the document.
- Verifies archive fingerprints locally and supports independent command-line checks.

## 1.0.0 - 2026-08-03

- Prepared the first production candidate for LibreOffice document
  fingerprinting.
- Added document registration, verification, archive copies, and manual
  verification tooling.
