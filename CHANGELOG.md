# Changelog

## 1.0.1 - 2026-08-04

- Published versioned LibreOffice package `digitalownership-1.0.1.oxt`.
- Kept `digitalownership.oxt` as a compatibility alias.
- Updated ODF fingerprinting to ignore regenerated `Thumbnails/` previews.
- Updated the standalone verifier to match the plugin hash algorithm.
- Added close/reopen regression coverage for ODF files.

## 1.0.0 - 2026-08-03

- Prepared the first production candidate for LibreOffice document
  fingerprinting.
- Added document registration, verification, metadata storage, archive copies,
  and manual verification tooling.
